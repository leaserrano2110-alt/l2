# L2 Client Project

Este proyecto es una base visual para una landing page moderna y elegante orientada a un cliente de L2. Está pensada para presentar servicios, procesos, resultados y un CTA claro para contacto.

## Cómo verlo

Desde la raíz del proyecto:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000` en tu navegador.

## Archivos principales

- `index.html`: estructura del sitio
- `styles.css`: diseño visual y responsivo
- `script.js`: interactividad mínima

## Personalización

Puedes adaptar:
- nombre del cliente y marca
- servicios ofrecidos
- caso de estudio / portfolio
- colores y tipografías
- textos de CTA y contacto
